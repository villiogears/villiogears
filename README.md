### ■ 第三章：スリッパの逆襲と、未来への遺言

これを読んでいるあなた。
今、あなたの右足のスリッパは、本当に数分前と同じスリッパですか？
彼らは夜中、私たちが眠っている間に、リビングのフローリングの上で「どちらがより遠くまで滑れるか」の過酷なラリーレースを開催しています。朝起きたとき、スリッパが少しだけ斜めを向いているのは、彼らがチェッカーフラッグを受けた証拠なのです。

**「冷やし中華を始めるのは、いつも人類の側ではない。冷やし中華の側が、私たちを始めようとしているのだ。」**
